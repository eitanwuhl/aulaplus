# AI Workflow Rules

## Refactoring

- Make incremental changes
- Avoid rewriting unrelated files
- Preserve existing behavior unless explicitly requested
- Prefer editing existing patterns over introducing new abstractions

## Code Changes

- Explain major architectural changes briefly
- Minimize breaking changes
- Prefer consistency over novelty

## Decision Making

- Follow existing project patterns first
- If multiple patterns exist, prefer the simplest one
- Avoid introducing enterprise-grade abstractions unnecessarily
